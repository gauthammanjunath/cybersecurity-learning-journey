# 🌐 Network Fundamentals (Cybersecurity Basics)

## 🎯 Objective

To understand core networking concepts essential for cybersecurity and penetration testing.

---

## 📡 IP Address

An IP address uniquely identifies a device on a network.

### IPv4

* 32-bit address
* Example: 192.168.0.1
* Range: 0.0.0.0 – 255.255.255.255

---

## 🧮 IP Classes

| Class | Range   | Structure |
| ----- | ------- | --------- |   Here N is for Network and H Stands for Host 
| A     | 0–127   | N.H.H.H   |
| B     | 128–191 | N.N.H.H   |
| C     | 192–223 | N.N.N.H   |

---

## 🧱 Subnet Mask

Defines network and host portions.

* Class A → 255.0.0.0
* Class B → 255.255.0.0
* Class C → 255.255.255.0

---

## 🔁 Private IP Ranges

* 10.0.0.0 – 10.255.255.255
* 172.16.0.0 – 172.31.255.255
* 192.168.0.0 – 192.168.255.255

---

## 🌍 Public vs Private IP

* Private → used inside networks
* Public → used on internet

---

## 🔌 MAC Address

* 48-bit hardware address
* Unique identifier for network interfaces

---

## 🔄 Routing

Routing determines how data travels between networks.

### Types:

* Static Routing → manual
* Dynamic Routing → automatic

---

## 🌐 Ports & Protocols

| Protocol | Port |
| -------- | ---- |
| HTTP     | 80   |
| HTTPS    | 443  |
| DNS      | 53   |

---

## 🚦 TCP vs UDP

* TCP → reliable, connection-based
* UDP → faster, connectionless

---

## 🧠 Key Takeaways

* Networking is the foundation of cybersecurity
* Understanding IP, ports, and routing is essential
* Every attack and defense relies on network concepts
