# 🖧 Cisco Packet Tracer Basics

## 🎯 Objective

To simulate and understand network communication using Cisco Packet Tracer.

---

## 🧪 Lab Setup

* 2 PCs
* 1 Switch
* Connect using cables

---

## 🔌 Steps

1. Add devices (PCs, Switch)
2. Connect using copper straight-through cable
3. Assign IP addresses

Example:
PC1 → 192.168.0.1
PC2 → 192.168.0.2

---

## 🔍 Testing Connectivity

Use ping command:

ping 192.168.0.2

---

## 📌 Result

* Successful ping → network working
* Failure → check IP or connections

---

## 🧠 Key Takeaways

* Helps visualize network communication
* Useful for understanding routing and switching
* Important for cybersecurity fundamentals
