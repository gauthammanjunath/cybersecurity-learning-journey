# 🌐 HTTP (HyperText Transfer Protocol)

## 🎯 Objective

To understand how web communication works between a client and a server using HTTP.

---

## 🧠 What is HTTP?

HTTP is a protocol used to transfer data between a client (browser) and a web server.

---

## 🔄 How HTTP Works

1. Client sends request (browser)
2. Server processes request
3. Server sends response

---

## 📡 HTTP Protocol

* Port: 80
* Works over TCP

---

## 🔐 HTTPS

* Secure version of HTTP
* Uses encryption (SSL/TLS)
* Port: 443

---

## 📌 HTTP Methods

### GET

* Retrieve data from server

### POST

* Send data to server

### PUT

* Update data

### DELETE

* Delete data

---

## 📦 HTTP Request Structure

Example:

GET /index.html HTTP/1.1
Host: example.com

---

## 📦 HTTP Response Structure

Example:

HTTP/1.1 200 OK
Content-Type: text/html

---

## 🔐 HTTP in Cybersecurity

* Used in web attacks (XSS, SQL Injection)
* Sensitive data can be exposed in HTTP
* HTTPS protects data using encryption

---

## 🧠 Key Takeaways

* HTTP enables web communication
* Works on port 80
* HTTPS provides secure communication
