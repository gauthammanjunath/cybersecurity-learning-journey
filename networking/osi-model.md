# 🌐 OSI Model (Open Systems Interconnection)

## 🎯 Objective

To understand the 7 layers of the OSI model and their role in network communication.

---

## 🧠 What is OSI Model?

The OSI model is a conceptual framework that describes how data travels from one system to another in a network.

---

## 🧱 7 Layers of OSI Model

### 7️⃣ Application Layer

* Interface between user and network
* Examples: HTTP, HTTPS, FTP, DNS

---

### 6️⃣ Presentation Layer

* Data formatting and encryption
* Converts data into readable format

---

### 5️⃣ Session Layer

* Manages communication sessions
* Establishes and terminates connections

---

### 4️⃣ Transport Layer

* Ensures reliable data delivery
* Protocols: TCP, UDP

---

### 3️⃣ Network Layer

* Handles IP addressing and routing
* Protocol: IP

---

### 2️⃣ Data Link Layer

* Handles MAC address and local network communication
* Works with switches

---

### 1️⃣ Physical Layer

* Transmits raw bits over medium
* Example: cables, signals

---

## 🔄 Data Flow

Sender → Layer 7 → Layer 1 → Network → Layer 1 → Layer 7 → Receiver

---

## 📌 Example Mapping

* HTTP → Application Layer
* TCP → Transport Layer
* IP → Network Layer
* MAC → Data Link Layer

---

## 🧠 Key Takeaways

* OSI model helps understand how networks work
* Each layer has a specific role
* Important for troubleshooting and security analysis

Example:
When accessing a website:
HTTP (Application) → TCP (Transport) → IP (Network) → MAC (Data Link)
