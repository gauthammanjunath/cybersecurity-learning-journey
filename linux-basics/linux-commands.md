# 🐧 Linux Basic Commands

## 🎯 Objective

To understand essential Linux commands used in cybersecurity and system administration.

---

## 📂 File & Directory Commands

### pwd

Prints the current working directory.

### ls

Lists files and directories.

### cd

Changes directory.

### mkdir

Creates a new directory.

### rm -rf

Deletes files/directories recursively.

---

## 👤 User Management

### adduser

Creates a new user.

### passwd

Sets or changes password.

### usermod

Modifies user properties.

---

## 🔐 File Permissions

Linux permissions:

* r = read (4)
* w = write (2)
* x = execute (1)

Example:
chmod 604 file.txt

---

## 🧠 Key Takeaways

* Linux is the foundation of cybersecurity
* Understanding file permissions is critical
* User management is essential for system security
